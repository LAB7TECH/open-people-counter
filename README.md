# Open People Counter

Open hardware LoRaWAN people counter for public buildings: museums, libraries, town halls.

- Multizone time-of-flight sensor, no camera, no personal data
- ESP32-S3, LoRaWAN and PoE on one board
- Self-hosted backend on ChirpStack, open payload codec
- Hardware under CERN-OHL-S

Status: planning. Work starts in this repository.

Maintained by LAB7 Technologies SRL, Cluj-Napoca, Romania.
